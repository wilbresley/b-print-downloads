# Licenças de terceiros

Cada GitHub Release oficial acompanha:

- `LICENSES.zip` com os termos completos e SBOMs;
- fontes correspondentes de `qtbase`, `qtsvg`, `qtimageformats` e
  `qttranslations` 6.8.2;
- `SHA256SUMS.txt`.

O b-print usa Qt por ligação dinâmica sob GNU LGPL v3. As DLLs ficam
substituíveis na pasta de instalação. Consulte `QT-LGPL-NOTICE.txt` e
`QT-SOURCE-OFFER.txt` dentro de `LICENSES.zip`.

Outros componentes incluídos:

- Lucide / Feather — ISC e MIT;
- Tabler Icons — MIT;
- Twemoji — CC-BY 4.0;
- libwebp — BSD 3-Clause;
- runtimes GCC/MinGW — licenças próprias e GCC Runtime Library Exception.

Os termos proprietários do b-print não reduzem os direitos concedidos por
essas licenças.
