# Privacy

[Português (Brasil)](PRIVACY.md)

b-print is designed to run locally on the user's computer.

## What the program does not do

- It does not upload screenshots.
- It does not require an account.
- It does not collect telemetry.
- It does not upload logs automatically.
- It does not provide cloud storage.
- It does not sell or share data.
- It does not use AI at runtime or send data to AI services.

## Local files

Settings, recent-history entries, and logs are stored under:

```text
%LOCALAPPDATA%\Programs\b-print\data
```

Images are saved only to folders chosen by the user.

## Logs

Logs contain technical events, warnings, errors, app version, and operations
such as saving or copying. They do not contain screenshot pixels or visual
capture content.

They may contain file paths, folder names, Windows technical information, and
timestamps. Logs leave the computer only if the user chooses to share them.
Review them before attaching them to a public Issue.

## Removal

The uninstaller removes the application folder, including settings and logs
stored there. Screenshots saved elsewhere are not deleted.
